How do I get a token?
  1. Open GitHub → New fine-grained token.
  2. Name it “Portfolio admin” and pick an expiration.
  3. Under Repository access, choose Only select repositories and pick your portfolio repo.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it, and paste it above. Keep it private: anyone with it can edit your site.
